# ATM System

A simple **ATM System** built using **HTML, CSS, and JavaScript** to demonstrate JavaScript **Events** and **DOM Manipulation**.

## Features

* Deposit Money
* Withdraw Money
* Check Current Balance
* Clear Input and Output
* Input Validation
* Insufficient Balance Check

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

```text
ATM-System/
│── index.html
│── style.css
│── script.js
└── README.md
```

## Functionality

* The application starts with an initial balance of **5000**.
* Users can deposit money into the account.
* Users can withdraw money if sufficient balance is available.
* The current balance can be viewed at any time.
* Invalid inputs are handled using JavaScript validation.

## Learning Objectives

This project helps students practice:

* JavaScript Events
* DOM Manipulation
* Variables
* Conditional Statements (`if...else`)
* Event Listeners
* Input Validation
